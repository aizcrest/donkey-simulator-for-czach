Original seven models were retrieved 2026-11-10; Donkey and Knight/Rider were added 2026-11-12. License metadata comes from each linked public model page. Copies of the CC BY 3.0 and CC0 legal texts are in `Licenses/`.

Conversion used Blender 4.3.2. `Tools/AssetSources/models.json` records download URLs and converted FBX hashes. Download the GLB files as `<kind>.glb`, then run `blender -b --python Tools/convert_models.py -- SOURCE_DIRECTORY`. To convert selected models only, append `--only Rider Donkey`. The rider adaptation and four original mounted clips are generated by `Tools/mounted_rider.py`. Runtime Unity import selects/reduces the clips actually used.

Quaternius animal pack information: https://quaternius.com/packs/ultimateanimatedanimals.html

The active donkey/rider now use original segmented models generated by `Tools/create_mounted_models.py`. The licensed Donkey and Knight files listed above are retained as reference assets and are not loaded for the player. Saddle, barding, sword, low-poly forest props, terrain textures, grass, altar/gems and effects are original project geometry. Bear and Moose source meshes are static; other included model files contain animation clips.

## Original audio

`Tools/generate_audio.py` creates the 19 mono WAV files in `Assets/Resources/Audio`. Effects, ambience and the short music loop are original synthesized project work, with no external sample recordings or third-party music license. It requires numpy when regenerating; Unity does not require Python or numpy to use the included WAVs.

The image `Docs/forest-rider-concept.png` is generated concept artwork, not a gameplay screenshot.
