# What is still missing

The playable feature set now includes native hilly terrain, free enemy/rider/donkey models, mounted animations, audio, loot/gear, four rider/mount skills, XP/training, contracts, elites, local saves, a ten-gem dragon encounter and saved quality controls.

Before a release: import/compile in Unity 2022.3.62f1; run the acceptance checklist and an actual boss playthrough; profile real budget phones for memory, heat and sustained FPS; validate touchscreen safe areas, quality changes and Android/iOS pause/resume; verify old saves, recovery files, audio levels and gameplay balance. Current automated checks cover engine-independent rules and assets, not those end-to-end behaviors.

Presentation gaps: the bear and moose are still static meshes, equipment attachments remain simple, animations/transitions need in-engine polish, sound effects are original synthetic prototypes, and there is no dedicated title screen or guided first-run tutorial. Accessibility controls, remappable input and more save slots are also future work.

Optional design expansions: a selectable-item inventory, crafting and merchants; more environments/points of interest; story/NPC quests and repeatable contracts; more bosses/attack patterns. The current four contracts are one-time goals, and the dragon victory is one-time per save. These expansions are not prerequisites for testing the existing game.
